## Como confirmar uma atualização

Uma versão só deve ser considerada **PUBLICADA** quando existirem os três itens abaixo:

1. Release `erp-v<VERSAO>` no GitHub.
2. Pacote `ERP_Gratidao_Update_v<VERSAO>.zip` anexado à Release.
3. `erp/versao.json` apontando para a mesma versão e contendo o SHA-256 gerado automaticamente.

Se algum desses três itens estiver ausente, a versão não está publicada para atualização automática.
